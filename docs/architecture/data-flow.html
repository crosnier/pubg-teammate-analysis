Keyed by match_id only. A match cached from looking up one player is reused automatically for any other player who shares it — one file can back many players' analyses.

playerstats/{name}.json Full response saved in full on every run — lifetime stats change as the player plays more, so staleness isn't acceptable here.
match-telemetry is the shared layer _is_cached() gates both API calls above it. Because the key is match_id, not player, one fetch backs every player who shares that match.
Indexes aren't their own API call player-index.json and bot-index.json are built from data already in flight elsewhere — loaded, updated in place, rewritten whole.
Source of truth: main.py, api/player_stats.py, api/telemetry_fetcher.py, api/player_index.py, api/bot_index.py, utils/io_helpers.py. api/rate_limiter.py paces requests in memory only — no persisted state.
